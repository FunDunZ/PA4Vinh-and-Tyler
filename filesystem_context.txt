Software Disk API (from softwaredisk.h):
- SOFTWARE_DISK_BLOCK_SIZE = 4096 bytes
- init_software_disk(): Initialize disk to all zeros
- software_disk_size(): Returns total number of blocks
- write_sd_block(buf, blocknum): Write block to disk
- read_sd_block(buf, blocknum): Read block from disk
- Error codes: SD_NONE, SD_NOT_INIT, SD_ILLEGAL_BLOCK_NUMBER, SD_INTERNAL_ERROR

Filesystem Block Layout:
0: SUPERBLOCK_BLOCK - Filesystem metadata
1: DATA_BITMAP_BLOCK - Data block allocation bitmap
2: INODE_BITMAP_BLOCK - Inode allocation bitmap
3-6: FIRST_INODE_BLOCK to LAST_INODE_BLOCK - Inode table (128 inodes per block)
7-70: FIRST_DIR_ENTRY_BLOCK to LAST_DIR_ENTRY_BLOCK - Directory entries
71-4095: FIRST_DATA_BLOCK to LAST_DATA_BLOCK - Data blocks

Key Implementation Details:
1. Inode Bitmap:
   - Stored in block 2 (INODE_BITMAP_BLOCK)
   - Tracks 512 inodes (4 blocks * 128 inodes per block)
   - Inode numbers range from 0 to 511
   - Each bit represents one inode (0 = free, 1 = allocated)

2. Data Block Bitmap:
   - Stored in block 1 (DATA_BITMAP_BLOCK)
   - Tracks data blocks from FIRST_DATA_BLOCK (71) to LAST_DATA_BLOCK (4095)
   - Each bit represents one data block
   - Block numbers are relative to FIRST_DATA_BLOCK

3. Inode Structure:
   - Contains 13 direct block numbers (uint16_t)
   - Contains 1 indirect block number (uint16_t)
   - Stores file size and inode number
   - Maximum file size: (13 + 2048) * 4096 bytes (direct + indirect blocks)

4. Directory Entries:
   - Stored in blocks FIRST_DIR_ENTRY_BLOCK (7) to LAST_DIR_ENTRY_BLOCK (70)
   - 8 entries per block
   - Each entry contains filename and inode number
   - Filenames can be up to 256 characters (nul-terminated ASCII)

Implemented Functions:
1. find_free_inode():
   - Scans inode bitmap for first free inode
   - Returns inode number (0-511) or -1 if no free inodes
   - Uses SOFTWARE_DISK_BLOCK_SIZE for bitmap buffer

2. allocate_inode():
   - Takes inode number (0-511)
   - Sets corresponding bit in inode bitmap
   - Returns 1 on success, 0 on failure

3. free_inode():
   - Takes inode number (0-511)
   - Clears corresponding bit in inode bitmap
   - Returns 1 on success, 0 on failure

4. find_free_data_block():
   - Scans data bitmap for first free block
   - Returns block number (71-4095) or -1 if no free blocks
   - Adds FIRST_DATA_BLOCK offset to relative position

5. allocate_data_block():
   - Takes block number (71-4095)
   - Sets corresponding bit in data bitmap
   - Returns 1 on success, 0 on failure

6. free_data_block():
   - Takes block number (71-4095)
   - Clears corresponding bit in data bitmap
   - Returns 1 on success, 0 on failure

Important Notes:
1. Inode numbers start from 0, not 1
2. Data block numbers start from 71 (FIRST_DATA_BLOCK)
3. Bitmap blocks are single blocks (4096 bytes)
4. Error handling uses fserror global variable
5. All functions must set fserror appropriately
6. No standard filesystem operations (fopen, etc.) allowed
7. Must handle concurrent access (thread safety optional)
8. Filenames must be nul-terminated ASCII strings
9. Maximum filename length: 256 characters
